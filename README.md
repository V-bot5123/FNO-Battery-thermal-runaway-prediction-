# FNO-Battery-thermal-runaway-prediction

## Overview
Predicting battery State of Health (SOH) and catastrophic Thermal Runaway in Lithium-ion batteries currently requires physically testing batteries for days or running computationally massive Finite Element Analysis (FEA) simulations. 

This project solves this bottleneck by using **Physics-Informed Fourier Neural Operators (FNO)** to evaluate heat physics 1000x faster than traditional PDE solvers. By predicting thermal dynamics instantly, this approach saves significant testing time and prevents dangerous battery fires in mass production pipelines.

## Our Approach: Why Fourier Neural Operators?
* **Why not standard AI (LSTMs/CNNs)?** Standard models ignore the laws of physics and are tied to specific grid resolutions. If trained on a 64x64 grid, they break on a 128x128 grid.
* **Why not PINNs?** Physics-Informed Neural Networks must be retrained for every single new initial condition, making them too slow for real-time inference.
* **The FNO Solution:** FNOs learn the underlying mathematical family of Partial Differential Equations (PDEs). By utilizing the Fourier Transform, they learn the physics in the *frequency domain*. This makes them **resolution-invariant** and capable of generalizing across all initial conditions instantly. Instead of heavy convolutions in spatial domains, we utilized the Convolution Theorem to perform simple multiplications in the frequency domain via Fast Fourier Transforms (`torch.fft`).

## File Structure & Guide

Here is a breakdown of the codebase and what each file does:

### 📁 `src/` (Source Code)
* **`data_generation.py`** 
  * **Aim:** Generate synthetic 2D heatmaps to train our AI.
  * **Technique:** Simulates a sharp initial thermal event (t=0) and a mathematically diffused state (t=1). This acts as our ground-truth data, bypassing the need for a slow physical FEA simulator for training.
* **`fno_model.py`**
  * **Aim:** Defines the PyTorch architecture for the Fourier Neural Operator.
  * **Technique:** Implements `SpectralConv2d` logic using Fast Fourier Transforms (`torch.fft`), combined with standard linear bypass layers. It converts spatial heat data to frequencies, filters out high-frequency noise, multiplies weights, and transforms it back to predict heat spread.
* **`train.py`**
  * **Aim:** Teaches the FNO model to map initial heat states to future diffused states.
  * **Technique:** PyTorch training loop using Mean Squared Error (MSE) loss and the Adam optimizer. We run this for 20 epochs to prove rapid convergence and physics learning.
* **`evaluate.py`**
  * **Aim:** Tests the trained model on unseen data and generates visualizations.
  * **Technique:** Runs inference on the test dataset and uses `matplotlib` to plot a side-by-side comparison of the Initial State, the True Final State (FEA), and the FNO Predicted State.

### 📁 `docs/` (Documentation)
* **`Project_Report.md`**: A formal breakdown of the problem, methodology, and results.
* **`Final_Evaluation_Presentation.md`**: Slide outlines for presenting the project.

### 📁 `results/` & `models/`
* **`results/`**: Stores the output PNG visualizations generated by `evaluate.py`.
* **`models/`**: Stores the saved PyTorch model weights (`.pt` files) after training.

## How to Run the Project
1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
2. **Run the Pipeline:**
   ```bash
   cd src
   python data_generation.py
   python train.py
   python evaluate.py
   ```
3. **View Results:** Open the `results/` folder to see the side-by-side heat map predictions!
